Kale App — iPhone Setup (Expo Go)

You need

  • Mac + iPhone on the same Wi‑Fi
  • Expo Go from the App Store
  • Node.js from nodejs.org (LTS)
  • GitHub access to the Kale repo (Kale will invite you)
  • A .env.local file from Kale (do not share it)

One-time setup (Mac)

  1. Install Node.js from nodejs.org
  2. Open Terminal
  3. Clone the repo from GitHub:
    cd ~/Downloads
git clone https://github.com/JannatTariq0808/kale-mobile-app.git
cd kale-mobile-app
    If asked to sign in to GitHub, use your GitHub account.
  4. Install dependencies:
    npm install
  5. Put .env.local in the kale-mobile-app folder (from Kale)

Run the app (each time)

  1. In Terminal:
    cd ~/Downloads/kale-mobile-app
npm run start:go
  2. A QR code appears on your Mac
  3. On iPhone: open Camera → scan QR → open in Expo Go
    Or open Expo Go → Scan QR code
  4. Keep Terminal open while testing

Get latest code (optional)

  1. In Terminal:
    cd ~/Downloads/kale-mobile-app
git pull
npm install

If it won’t load

  1. Same Wi‑Fi on Mac and iPhone
  2. Restart with cache clear:
    npm run start:go -- --clear
  3. Try tunnel mode:
    npx expo start --tunnel
    Then scan the new QR code
  4. Update Expo Go in the App Store

Important

  • Use npm run start:go — not npm start
  • Do not share .env.local
