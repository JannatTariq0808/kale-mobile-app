COPY THESE FILES INTO YOUR VERCEL WEBSITE PROJECT
=================================================

Your website repo is SEPARATE from kale-mobile-app.
Open the kale.insure website project in Finder/VS Code.

If the site uses Next.js / Vite / most frameworks, copy into the "public" folder
at the ROOT of that website repo:

  YOUR-WEBSITE-REPO/
    public/                          <-- copy INTO this folder
      .well-known/
        assetlinks.json              <-- from kale-mobile-app/hosting/public/.well-known/
        apple-app-site-association   <-- from kale-mobile-app/hosting/public/.well-known/
      apple-app-site-association     <-- from kale-mobile-app/hosting/public/
      reset-password/
        index.html                   <-- from kale-mobile-app/hosting/public/reset-password/

Also merge the "headers" section from kale-mobile-app/hosting/vercel.json
into YOUR website's vercel.json (at the root of the website repo).

Then git commit + push. Vercel redeploys automatically.

After deploy, these URLs must work in a browser:
  https://www.kale.insure/.well-known/assetlinks.json
  https://www.kale.insure/.well-known/apple-app-site-association
  https://www.kale.insure/reset-password

Your Firebase email link already uses /reset-password — that matches now.

DO NOT copy into kale-mobile-app. Copy into the WEBSITE repo only.
